# Teclaton (versão anterior deste repositório)

Este diretório guarda os arquivos do projeto original **Teclaton** — o
instrumento de teclado inspirado no Patatap, escrito em HTML/CSS/JS puro.

O `index.html` e o `js/app.js` da raiz foram substituídos pela **Vitrine**,
a plataforma de e-commerce. Os quatro arquivos abaixo continuam intactos e
também permanecem no histórico do Git (`git log`), então nada foi perdido:

| Arquivo | O que era |
|---|---|
| `style.css` | estilos do Teclaton |
| `audio.js` | motor de som (71 timbres sintetizados) |
| `packs.js` | os 8 universos sonoros × 36 teclas |
| `visuals.js` | motor visual (20 formas em Canvas) |

Para recuperar o projeto antigo: `git checkout <commit-antigo> -- index.html js/app.js`
